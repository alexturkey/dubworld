> Το DubWorld μεταγλωττίζει τα βίντεό σας σε άλλη γλώσσα κατευθείαν στον δικό σας υπολογιστή, χωρίς να τα ανεβάζει σε καμία online υπηρεσία: μετατρέπει την ομιλία σε κείμενο μαζί με τον χρόνο κάθε λέξης, τη μεταφράζει και την εκφωνεί με μια τεχνητή (AI) φωνή που μένει συγχρονισμένη με το αρχικό βίντεο (η ομιλία επιταχύνεται το πολύ 1,25 φορές, την υπόλοιπη διαφορά την απορροφά μια ήπια αλλαγή στον ρυθμό του βίντεο), προσθέτει υπότιτλους και φτιάχνει νέο βίντεο. Προεπιλεγμένη γλώσσα είναι τα τουρκικά· τα ελληνικά και οι άλλες γλώσσες εξαρτώνται από τη μηχανή φωνής που επιλέγετε ([docs/diller.md](docs/diller.md)).

## Αφήστε τον βοηθό AI να το εγκαταστήσει

Δεν χρειάζεται να ξέρετε προγραμματισμό. Ανοίξτε έναν βοηθό AI που μπορεί να εκτελεί εντολές στον υπολογιστή σας (Claude Code, Codex,
Gemini CLI ή κάτι αντίστοιχο) και επικολλήστε αυτή τη μία πρόταση:

```text
Install the video dubbing program from https://github.com/alexturkey/DubWorld on this computer. Follow the AGENTS.md file in that repository step by step, detect my hardware yourself and do not ask me technical questions. When `dubla kontrol` says READY and the sample dub works, open the program's window for me.
```

Ο βοηθός ελέγχει τον υπολογιστή σας (κάρτα γραφικών, επεξεργαστή, μνήμη, δίσκο) και ρωτά μόνο μία φορά, με απλά λόγια, τι
εγκατάσταση θέλετε: γρήγορη, προτεινόμενη για τον υπολογιστή σας ή πλήρη. Εξηγεί κάθε εξάρτημα (τι κάνει, πόσο χώρο πιάνει,
πόσο κρατά η εγκατάσταση, ποια άδεια έχει) και, ξεκινώντας από την προεπιλεγμένη φωνή, ρωτά αν αποδέχεστε τους όρους χρήσης
των επιλεγμένων εξαρτημάτων. Μετά εγκαθιστά, φτιάχνει μια δοκιμαστική μεταγλώττιση και ανοίγει το παράθυρο του προγράμματος.
Πρώτα βήματα και συνηθισμένα προβλήματα, με απλά λόγια (στα αγγλικά): **[docs/getting-started.md](docs/getting-started.md)**.

**Άδειες με μια ματιά:** κώδικας Apache-2.0. Προεπιλεγμένα μοντέλα: φωνή Supertonic 3 με OpenRAIL-M (περιορισμοί χρήσης, αποδοχή μία φορά)· Opus-MT και το τουρκικό μοντέλο χρόνου λέξεων με CC BY 4.0 (υποχρεωτική αναφορά, NOTICE)· build του FFmpeg GPL-3.0 (ξεχωριστό πρόγραμμα). Μόνο για μη εμπορική χρήση και απενεργοποιημένα από προεπιλογή: CrisperWhisper 2.0, XTTS-v2 και τα μοντέλα χρόνου λέξεων WhisperX για fr / de / es / it. Το αποθετήριο δεν περιέχει κανένα βάρος μοντέλου ([THIRD_PARTY.md](THIRD_PARTY.md)).

## Γρήγορη εγκατάσταση

Windows 10/11 x64· δεν χρειάζεται προεγκατεστημένο Python, CUDA ή ffmpeg. Κάντε διπλό κλικ στο **`kur.cmd`** (ή εκτελέστε
`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\kur.ps1`)· το προφίλ GPU ή CPU επιλέγεται μόνο του
(το `-Cpu` επιβάλλει CPU). Μετά κάντε διπλό κλικ στο `arayuz.cmd` για να ανοίξει η εφαρμογή.
Όλα μένουν μέσα στον φάκελο του αποθετηρίου (`.venv`, `runtime_assets/`)· κάθε λήψη έχει κλειδωμένη έκδοση και
ελέγχεται με sha256. Ελεύθερος χώρος για να ξεκινήσετε: 22 GB με προφίλ GPU, 14 GB μόνο με CPU· μετρημένη χρήση μετά την εγκατάσταση ≈ 14,6 GB (GPU, τα αρχεία με hard link μετρήθηκαν μία φορά· η Εξερεύνηση αρχείων δείχνει ≈ 22 GB). Έλεγχος: `.venv\Scripts\dubla.exe kontrol`.

Απαιτήσεις, σειρά βημάτων, χάρτης περιβαλλόντων Python, προαιρετικές μηχανές, χρήση offline, ενημέρωση, απεγκατάσταση και
συνηθισμένα σφάλματα (στα αγγλικά): **[docs/installation.md](docs/installation.md)**. Linux και macOS δεν τα έχουμε δοκιμάσει ακόμα. Παράδειγμα: [παρουσίαση προϊόντος μεταγλωττισμένη σε αγγλικά, τουρκικά και αραβικά σε Mac με Apple M4, μόνο με CPU](https://x.com/MihenkAIdotcom/status/2114345171571925363).

## Χρήση

Εφαρμογή επιφάνειας εργασίας: διπλό κλικ στο `arayuz.cmd` (τοπική εφαρμογή web: `web.cmd`, μόνο στο 127.0.0.1). Η διεπαφή της εφαρμογής είναι προς το παρόν στα τουρκικά. Από τη γραμμή εντολών:

```powershell
.venv\Scripts\dubla.exe talk.mp4                            # recommended flow, Turkish dub
.venv\Scripts\dubla.exe talk.mp4 --ayar genel.hedef_dil=de  # another target language
```

Για μεταγλώττιση στα ελληνικά χρησιμοποιήστε `--ayar genel.hedef_dil=el` (η μετάφραση στα ελληνικά χρειάζεται Codex ή Claude Code). Τα αποτελέσματα πηγαίνουν στο `cikti/<video>_<time>/`: `dubbed_tr.mp4` (με την ετικέτα `AI-dubbed`), οι αρχικοί υπότιτλοι `transcript_<lang>.srt` και τα αρχεία εργασίας JSON· η τελευταία γραμμή `dubbed_video:` δίνει τη διαδρομή. Όλες οι ρυθμίσεις (στα αγγλικά και τουρκικά): [docs/tarifler/kombinasyonlar.md](docs/tarifler/kombinasyonlar.md).

## Πώς δουλεύει

1. **Ήχος:** το FFmpeg εξάγει τον ήχο· το προαιρετικό Demucs (MIT) ξεχωρίζει την ομιλία από το φόντο.
2. **Ομιλία σε κείμενο:** faster-whisper large-v3-turbo (MIT) με χρόνους λέξεων από wav2vec2 CTC (αγγλικά MIT, τουρκικά CC BY 4.0)· προαιρετικά CrisperWhisper 2.0 (μη εμπορικό) και άλλες μηχανές.
3. **Ομιλητές:** το 3D-Speaker CAM++ (Apache-2.0) και ένα μοντέλο αναγνώρισης φύλου (Apache-2.0) διαλέγουν μία φωνή AI για κάθε ομιλητή.
4. **Μετάφραση:** Codex CLI ή Claude Code CLI αν είναι εγκατεστημένα και συνδεδεμένα, αλλιώς τοπικό Opus-MT από αγγλικά σε τουρκικά (CC BY 4.0)· τα API backends είναι προαιρετικά.
5. **Φωνή και χρονισμός:** προεπιλογή Supertonic 3 (OpenRAIL-M), προαιρετικά VoxCPM2 (Apache-2.0) ή XTTS-v2 (μη εμπορικό)· κάθε φράση επιταχύνεται το πολύ 1,25 φορές προς τη διάρκεια του αρχικού τμήματος και το υπόλοιπο το αναλαμβάνει ο χρόνος του βίντεο, άρα η μεταγλώττιση μπορεί να βγει μεγαλύτερη από το πρωτότυπο.
6. **Βίντεο:** το FFmpeg γράφει τη νέα φωνή, υπότιτλους SRT / VTT / ASS και την ετικέτα `AI-dubbed`.

## Περιορισμοί

- Χωρίς CrisperWhisper (προαιρετική μηχανή 13), το faster-whisper μπορεί στα κινέζικα και στα ιαπωνικά να παραλείψει ομιλία ή να επινοήσει κείμενο που δεν ειπώθηκε (παρατηρήθηκε: χάθηκαν τα πρώτα ≈ 10 δ. ενός κινέζικου αποσπάσματος· μια κραυγή έγινε μια μεγάλη γραμμή «ああ…»).
- Το CI δοκιμάζει μόνο CPU· η διαδρομή GPU τρέχτηκε με το χέρι σε κάρτα Pascal 4 GB. Νέες κάρτες (RTX 50), Linux και macOS δεν έχουν δοκιμαστεί· οι βιβλιοθήκες GPU που εγκαθίστανται έχουν πυρήνες από Pascal έως RTX 50, ενώ η Maxwell χρησιμοποιεί το προφίλ CPU ([πίνακας υποστήριξης GPU, στα αγγλικά](docs/installation.md#1-system-requirements)).
- Ο offline μεταφραστής κάνει μόνο αγγλικά προς τουρκικά· άλλα ζεύγη γλωσσών χρειάζονται Codex / Claude Code CLI ή API backend.
- Χρόνοι λέξεων για γλώσσες πηγής εκτός αγγλικών και τουρκικών: ιαπωνικά και κινέζικα μέσω `scripts/kur.ps1 -Adim hizalama-diller`, οι υπόλοιπες μετά από μία εκτέλεση με `DUBLAJ_CEVRIMICI=1`.
- Δεν έχουν δοκιμαστεί ακόμα από την αρχή ως το τέλος: πραγματική εγκατάσταση XTTS-v2, RVC, bot Telegram συνδεδεμένο σε πραγματική υπηρεσία και CrisperWhisper 2 Medium· το Moonshine είναι πειραματικό. Το CrisperWhisper 2.0 Turbo (μηχανή 13) δοκιμάστηκε με πραγματικό ήχο σε GTX 1050 Ti 4 GB (tr, en, ja· ≈ 1,4 GB VRAM).

## Δομικά στοιχεία

Κάθε στάδιο τρέχει και μόνο του, από τη γραμμή εντολών ή από Python, και οι μορφές αρχείων ανάμεσα στα στάδια είναι τεκμηριωμένες
(χάρτης σταδίων και JSON Schema: [docs/mimari.md](docs/mimari.md)):

```bash
dubla yaziya-dok talk.mp4 -o talk.json          # speech-to-text + word times (also: indir, ses-cikar, ayir, hizala)
dubla cevir talk.json -o talk.tr.json            # translation, timing kept
dubla seslendir talk.tr.json -o tts/             # timed speech (or plain text -> WAV)
dubla altyazi talk.json --kip karaoke -o k.ass   # SRT / VTT / ASS, word and karaoke modes
dubla birlestir talk.mp4 -o out.mp4 --ses tts/speech.wav --altyazi talk.tr.srt
```

Το `from dublaj_hatti import api` δίνει τα ίδια στάδια ως συναρτήσεις. Εγκαταστήστε μόνο ό,τι χρειάζεται ένα στάδιο, για παράδειγμα
`pip install -e ".[stt,hizalama,cpu]"` για υπότιτλους. Πέντε μικρά εργαλεία φτιαγμένα από αυτά τα στοιχεία: [examples/](examples/).

## Υπεύθυνη χρήση

> **Νομική σημείωση.** Έχετε την πλήρη ευθύνη για το περιεχόμενο που επεξεργάζεστε και δημοσιεύετε με αυτό το λογισμικό,
> καθώς και για την τήρηση των νόμων της χώρας σας και των όρων των ιστότοπων και υπηρεσιών που χρησιμοποιείτε. Το λογισμικό
> παρέχεται «ως έχει», χωρίς καμία εγγύηση (Apache-2.0). Πλήρες κείμενο: [ETHICS.md](ETHICS.md).

- **Δικαιώματα και συναίνεση.** Επεξεργαστείτε μόνο περιεχόμενο που σας ανήκει ή που έχετε δικαίωμα να μεταφράσετε και να ξαναμεταγλωττίσετε,
  και ζητήστε τη συναίνεση των αναγνωρίσιμων προσώπων που εμφανίζονται.
- **Φωνές.** Καμία μίμηση κανενός. Η φωνή αναφοράς μπορεί να είναι μόνο η δική σας ή κάποιου που έδωσε ρητή άδεια.
- **Σήμανση.** Το αποτέλεσμα φέρει την ετικέτα μεταδεδομένων `AI-dubbed`· αφήστε τη και πείτε στο κοινό σας με εμφανή τρόπο
  ότι η μεταγλώττιση έγινε με AI (Άρθρο 50 του Κανονισμού ΕΕ για την AI· άδεια Supertonic).
- **Λήψεις.** Τα προαιρετικά πρόσθετα `youtube` (yt-dlp) και `galeri` (gallery-dl) είναι μόνο για περιεχόμενο που σας ανήκει ή που επιτρέπεται να κατεβάσετε· ισχύουν οι όροι του ιστότοπου και
  η τοπική σας νομοθεσία.
- **Μη εμπορικές μηχανές.** Τα CrisperWhisper 2.0 και XTTS-v2 είναι μόνο για μη εμπορική χρήση (απενεργοποιημένα από προεπιλογή). Πριν από επί πληρωμή δουλειά ή δουλειά για πελάτη,
  δείτε τη στήλη **Commercial?** στο [THIRD_PARTY.md](THIRD_PARTY.md).
  Τα μοντέλα χρόνου λέξεων για ήχο πηγής fr / de / es / it (CC BY-NC 4.0) είναι επίσης μη εμπορικά και ζητούν συναίνεση στην πρώτη χρήση.
