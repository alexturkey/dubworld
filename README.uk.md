> DubWorld озвучує ваші відео іншою мовою просто на вашому комп'ютері, без завантаження на будь-який онлайн-сервіс: перетворює мовлення на текст із часом кожного слова, перекладає його, а потім озвучує штучним (ШІ) голосом, який іде в такт з оригіналом (мовлення пришвидшується щонайбільше в 1,25 раза, решту різниці вирівнює легка зміна темпу відео), додає субтитри й створює нове відео. Мова за замовчуванням — турецька; українська та інші мови залежать від обраного голосового рушія ([docs/diller.md](docs/diller.md)).

## Нехай ваш ШІ-асистент усе встановить

Програмувати не потрібно. Відкрийте ШІ-асистента, який уміє виконувати команди на вашому комп'ютері (Claude Code, Codex,
Gemini CLI або подібний), і вставте одне це речення:

```text
Install the video dubbing program from https://github.com/alexturkey/DubWorld on this computer. Follow the AGENTS.md file in that repository step by step, detect my hardware yourself and do not ask me technical questions. When `dubla kontrol` says READY and the sample dub works, open the program's window for me.
```

Асистент перевірить ваш комп'ютер (відеокарту, процесор, пам'ять, диск) і лише один раз, простими словами, запитає, яке
встановлення вам потрібне: швидке, рекомендоване для вашого комп'ютера чи повне. Він пояснить кожен компонент (що робить,
скільки місця займає, скільки триває встановлення, яка в нього ліцензія) і, починаючи з голосу за замовчуванням, запитає, чи
приймаєте ви умови використання обраних компонентів. Потім він усе встановить, зробить пробне озвучення й відкриє вікно програми.
Перші кроки й типові проблеми, простими словами (англійською): **[docs/getting-started.md](docs/getting-started.md)**.

**Ліцензії коротко:** код Apache-2.0. Моделі за замовчуванням: голос Supertonic 3 за OpenRAIL-M (обмеження використання, приймаються один раз); Opus-MT і турецька модель часу слів за CC BY 4.0 (обов'язкове зазначення авторства, NOTICE); збірка FFmpeg GPL-3.0 (окрема програма). Лише для некомерційного використання й вимкнені за замовчуванням: CrisperWhisper 2.0, XTTS-v2 і моделі часу слів WhisperX для fr / de / es / it. Цей репозиторій не містить жодних ваг моделей ([THIRD_PARTY.md](THIRD_PARTY.md)).

## Швидке встановлення

Windows 10/11 x64; заздалегідь встановлювати Python, CUDA чи ffmpeg не треба. Двічі клацніть **`kur.cmd`** (або виконайте
`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\kur.ps1`); профіль GPU чи CPU обирається сам
(`-Cpu` примусово вмикає CPU). Потім двічі клацніть `arayuz.cmd`, щоб відкрити застосунок.
Усе лишається в теці репозиторію (`.venv`, `runtime_assets/`); кожне завантаження має закріплену версію й
перевіряється sha256. Вільне місце для старту: 22 ГБ із профілем GPU, 14 ГБ лише з CPU; виміряне використання після встановлення ≈ 14,6 ГБ (GPU, файли з жорсткими посиланнями враховано один раз; Провідник показує ≈ 22 ГБ). Перевірка: `.venv\Scripts\dubla.exe kontrol`.

Вимоги, порядок кроків, карта середовищ Python, додаткові рушії, робота офлайн, оновлення, видалення й
типові помилки (англійською): **[docs/installation.md](docs/installation.md)**. Linux і macOS ми ще не тестували. Приклад: [продуктовий огляд, озвучений англійською, турецькою та арабською на Mac з Apple M4, лише на CPU](https://x.com/MihenkAIdotcom/status/2114345171571925363).

## Як користуватися

Настільний застосунок: подвійний клік на `arayuz.cmd` (локальний вебзастосунок: `web.cmd`, лише на 127.0.0.1). Інтерфейс застосунку поки що турецькою. З командного рядка:

```powershell
.venv\Scripts\dubla.exe talk.mp4                            # recommended flow, Turkish dub
.venv\Scripts\dubla.exe talk.mp4 --ayar genel.hedef_dil=de  # another target language
```

Щоб озвучити українською, використайте `--ayar genel.hedef_dil=uk` (переклад українською потребує Codex або Claude Code). Результати потрапляють у `cikti/<video>_<time>/`: `dubbed_tr.mp4` (з позначкою `AI-dubbed`), оригінальні субтитри `transcript_<lang>.srt` і робочі файли JSON; останній рядок `dubbed_video:` показує шлях. Усі налаштування (англійською й турецькою): [docs/tarifler/kombinasyonlar.md](docs/tarifler/kombinasyonlar.md).

## Як це працює

1. **Звук:** FFmpeg витягає звукову доріжку; додатковий Demucs (MIT) відокремлює мовлення від фону.
2. **Мовлення в текст:** faster-whisper large-v3-turbo (MIT) з часом слів від wav2vec2 CTC (англійська MIT, турецька CC BY 4.0); додатково CrisperWhisper 2.0 (некомерційний) та інші рушії.
3. **Мовці:** 3D-Speaker CAM++ (Apache-2.0) і модель розпізнавання статі (Apache-2.0) підбирають кожному мовцю один ШІ-голос.
4. **Переклад:** Codex CLI або Claude Code CLI, якщо вони встановлені й ви увійшли в обліковий запис, інакше локальний Opus-MT з англійської на турецьку (CC BY 4.0); API-бекенди необов'язкові.
5. **Голос і таймінг:** за замовчуванням Supertonic 3 (OpenRAIL-M), додатково VoxCPM2 (Apache-2.0) або XTTS-v2 (некомерційний); кожна репліка пришвидшується щонайбільше в 1,25 раза до тривалості оригінального фрагмента, решту вирівнює час відео, тож озвучення може бути довшим за оригінал.
6. **Відео:** FFmpeg записує новий голос, субтитри SRT / VTT / ASS і позначку `AI-dubbed`.

## Вимірювання

Еталонний комп'ютер: GPU Pascal 4 ГБ, Windows 10; методика й усі рядки в [docs/olcumler.md](docs/olcumler.md).

| Що | Профіль CPU | Профіль GPU |
|---|---|---|
| Перше встановлення, кроки за замовчуванням, від початку до кінця | ≈ 38 хв | ≈ 44 хв (пакети 13,7 хв) |
| Диск після встановлення | ≈ 13,2 ГБ (сума тек) | ≈ 14,6 ГБ (жорсткі посилання один раз) |
| Пробне озвучення 9 с, офлайн-переклад | 528 с | 376 с |
| Англійський кліп 30 с, Demucs, переклад Claude Code | – | 744 с |

## Обмеження

- Без CrisperWhisper (додатковий рушій 13) faster-whisper китайською та японською може пропускати мовлення або вигадувати текст, якого ніхто не казав (помічено: втрачені перші ≈ 10 с китайського кліпу; крик перетворився на довгий рядок «ああ…»).
- CI тестує лише CPU; шлях GPU запускали вручну на картці Pascal 4 ГБ. Нові картки (RTX 50), Linux і macOS не перевірені; встановлювані GPU-бібліотеки мають ядра від Pascal до RTX 50, а Maxwell використовує профіль CPU ([таблиця підтримки GPU, англійською](docs/installation.md#1-system-requirements)).
- Офлайн-перекладач уміє лише з англійської на турецьку; інші мовні пари потребують Codex / Claude Code CLI або API-бекенду.
- Час слів для вихідних мов, крім англійської й турецької: японська й китайська через `scripts/kur.ps1 -Adim hizalama-diller`, інші після одного запуску з `DUBLAJ_CEVRIMICI=1`.
- Ще не перевірено від початку до кінця: справжнє встановлення XTTS-v2, RVC, Telegram-бот, підключений до справжнього сервісу, і CrisperWhisper 2 Medium; Moonshine експериментальний. CrisperWhisper 2.0 Turbo (рушій 13) перевірено на справжньому аудіо на GTX 1050 Ti 4 ГБ (tr, en, ja; ≈ 1,4 ГБ VRAM).

## Будівельні блоки

Кожен етап працює й окремо, з командного рядка або з Python, а формати файлів між етапами задокументовано
(карта етапів і JSON Schema: [docs/mimari.md](docs/mimari.md)):

```bash
dubla yaziya-dok talk.mp4 -o talk.json          # speech-to-text + word times (also: indir, ses-cikar, ayir, hizala)
dubla cevir talk.json -o talk.tr.json            # translation, timing kept
dubla seslendir talk.tr.json -o tts/             # timed speech (or plain text -> WAV)
dubla altyazi talk.json --kip karaoke -o k.ass   # SRT / VTT / ASS, word and karaoke modes
dubla birlestir talk.mp4 -o out.mp4 --ses tts/speech.wav --altyazi talk.tr.srt
```

`from dublaj_hatti import api` дає ті самі етапи як функції. Встановлюйте лише те, що потрібно етапу, наприклад
`pip install -e ".[stt,hizalama,cpu]"` для субтитрів. П'ять маленьких інструментів, зібраних із цих блоків: [examples/](examples/).
