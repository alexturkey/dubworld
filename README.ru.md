## Пусть установку выполнит ИИ-ассистент

Программировать не нужно. Откройте ИИ-ассистента, который умеет выполнять команды на вашем компьютере (Claude Code,
Codex, Gemini CLI или аналог), и вставьте одно предложение:

```text
Установи на этот компьютер программу для дубляжа видео из __REPO_URL__. Шаг за шагом следуй файлу AGENTS.md в этом репозитории, сам определи моё оборудование и не задавай мне технических вопросов. Когда `dubla kontrol` покажет READY и пример дубляжа сработает, открой для меня окно программы.
```

Ассистент проверит компьютер, сам выберет установку с видеокартой (GPU) или только с процессором (CPU) и задаст вам
один вопрос: принимаете ли вы условия использования голоса. Затем откроется окно программы. Первые шаги, простые
объяснения и частые проблемы (на английском): **[docs/getting-started.md](docs/getting-started.md)**.

**Сводка лицензий:** код Apache-2.0. __LISANS_KUTUSU__ (лицензии моделей/данных, отличные от лицензии кода; «нет», если всё совместимо с Apache)

## Быстрая установка

Windows 10/11 x64; заранее не нужны ни Python, ни CUDA, ни ffmpeg. Дважды щёлкните **`kur.cmd`** (или выполните
`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\kur.ps1`); профиль GPU или CPU выбирается автоматически
(`-Cpu` принудительно включает CPU). Затем дважды щёлкните `arayuz.cmd`, чтобы открыть приложение.
Всё устанавливается внутрь папки репозитория (`.venv`, `runtime_assets/`); каждая загрузка имеет фиксированную версию
и проверяется по sha256. Диск: ≈ 22 ГБ с профилем GPU, ≈ 13 ГБ только CPU. Проверка: `.venv\Scripts\dubla.exe kontrol`.

Требования, порядок шагов, карта окружений Python, дополнительные движки, работа без сети, обновление, удаление и
частые ошибки (на английском): **[docs/installation.md](docs/installation.md)**. Linux и macOS пока не проверялись.

## Строительные блоки

Каждый этап работает отдельно, из командной строки или из Python, с документированными форматами файлов между этапами
(карта этапов и JSON-схемы: [docs/mimari.md](docs/mimari.md)):

```bash
dubla yaziya-dok talk.mp4 -o talk.json          # speech-to-text + word times (also: indir, ses-cikar, ayir, hizala)
dubla cevir talk.json -o talk.tr.json            # translation, timing kept
dubla seslendir talk.tr.json -o tts/             # timed speech (or plain text -> WAV)
dubla altyazi talk.json --kip karaoke -o k.ass   # SRT / VTT / ASS, word and karaoke modes
dubla birlestir talk.mp4 -o out.mp4 --ses tts/speech.wav --altyazi talk.tr.srt
```

`from dublaj_hatti import api` даёт те же этапы в виде функций. Устанавливайте только то, что нужно этапу, например
`pip install -e ".[stt,hizalama,cpu]"` для субтитров. Пять небольших инструментов из этих блоков: [examples/](examples/).
