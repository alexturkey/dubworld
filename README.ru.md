> DubWorld озвучивает видео на другом языке прямо на вашем компьютере: распознавание речи с метками времени слов, перевод, синтетический голос в такт исходному видео (речь ускоряется не более чем в 1,25 раза, остальное выравнивается по видео), субтитры и новое видео. По умолчанию турецкий; другие языки зависят от движка озвучки ([docs/diller.md](docs/diller.md)).

## Пусть установку выполнит ИИ-ассистент

Программировать не нужно. Откройте ИИ-ассистента, который умеет выполнять команды на вашем компьютере (Claude Code,
Codex, Gemini CLI или аналог), и вставьте одно предложение:

```text
Установи на этот компьютер программу для дубляжа видео из https://github.com/alexturkey/DubWorld. Шаг за шагом следуй файлу AGENTS.md в этом репозитории, сам определи моё оборудование и не задавай мне технических вопросов. Когда `dubla kontrol` покажет READY и пример дубляжа сработает, открой для меня окно программы.
```

Ассистент измерит компьютер (видеокарта, процессор, память, диск) и один раз простыми словами спросит, какую установку
вы хотите: быструю, рекомендуемую для вашего компьютера или полную. Он объяснит каждую часть (что она делает, сколько
места на диске и времени занимает, какая у неё лицензия) и спросит, принимаете ли вы условия использования выбранных
частей, начиная с голоса по умолчанию. Затем он установит программу, сделает пробный дубляж и откроет окно программы.
Первые шаги, простые объяснения и частые проблемы (на английском):
**[docs/getting-started.md](docs/getting-started.md)**.

**Сводка лицензий:** код Apache-2.0. Модели по умолчанию: голос Supertonic 3 под OpenRAIL-M (ограничения использования, согласие один раз); Opus-MT и турецкая модель меток времени слов под CC BY 4.0 (указание авторства, NOTICE); сборка FFmpeg под GPL-3.0 (отдельная программа). Только некоммерческие и выключены по умолчанию: CrisperWhisper 2.0, XTTS-v2, модели меток времени WhisperX для fr / de / es / it. Весов моделей в этом репозитории нет ([THIRD_PARTY.md](THIRD_PARTY.md)).

## Быстрая установка

Windows 10/11 x64; заранее не нужны ни Python, ни CUDA, ни ffmpeg. Дважды щёлкните **`kur.cmd`** (или выполните
`powershell -NoProfile -ExecutionPolicy Bypass -File scripts\kur.ps1`); профиль GPU или CPU выбирается автоматически
(`-Cpu` принудительно включает CPU). Затем дважды щёлкните `arayuz.cmd`, чтобы открыть приложение.
Всё устанавливается внутрь папки репозитория (`.venv`, `runtime_assets/`); каждая загрузка имеет фиксированную версию
и проверяется по sha256. Свободно на диске для начала: 22 ГБ с профилем GPU, 14 ГБ только CPU; измеренный объём после установки ≈ 14,6 ГБ (GPU, файлы с жёсткими ссылками учтены один раз; проводник показывает ≈ 22 ГБ). Проверка: `.venv\Scripts\dubla.exe kontrol`.

Требования, порядок шагов, карта окружений Python, дополнительные движки, работа без сети, обновление, удаление и
частые ошибки (на английском): **[docs/installation.md](docs/installation.md)**. Linux и macOS пока не проверялись. Пример: [обзор продукта, озвученный на английском, турецком и арабском на Apple M4 Mac, только CPU](https://x.com/MihenkAIdotcom/status/2114345171571925363).

## Использование

Настольное приложение: двойной щелчок по `arayuz.cmd` (локальное веб-приложение: `web.cmd`, только 127.0.0.1). Интерфейс приложения — на английском и турецком: язык выбирается справа вверху (если система на другом языке, приложение откроется на английском). Из командной строки:

```powershell
.venv\Scripts\dubla.exe talk.mp4                            # recommended flow, Turkish dub
.venv\Scripts\dubla.exe talk.mp4 --ayar genel.hedef_dil=de  # another target language
```

Результаты попадают в `cikti/<video>_<time>/`: `dubbed_tr.mp4` (с меткой `AI-dubbed`), исходные субтитры `transcript_<lang>.srt` и JSON-файлы задания; последняя строка `dubbed_video:` выводит путь. Все настройки: [docs/tarifler/kombinasyonlar.md](docs/tarifler/kombinasyonlar.md).

## Как это работает

1. **Звук:** FFmpeg извлекает звук; необязательный Demucs (MIT) отделяет речь от фона.
2. **Речь в текст:** faster-whisper large-v3-turbo (MIT) плюс метки времени слов wav2vec2 CTC (английский MIT, турецкий CC BY 4.0); необязательно CrisperWhisper 2.0 (некоммерческий) и другие движки.
3. **Говорящие:** 3D-Speaker CAM++ (Apache-2.0) и классификатор пола (Apache-2.0) выбирают синтетический голос для каждого говорящего.
4. **Перевод:** Codex CLI или Claude Code CLI, если они установлены и выполнен вход, иначе локальный Opus-MT с английского на турецкий (CC BY 4.0); API-бэкенды необязательны.
5. **Голос и тайминг:** по умолчанию Supertonic 3 (OpenRAIL-M), по желанию VoxCPM2 (Apache-2.0) или XTTS-v2 (некоммерческий); каждая реплика ускоряется не более чем в 1,25 раза к длительности исходного сегмента, остальное выравнивается по видео, поэтому дубляж может быть длиннее исходника.
6. **Видео:** FFmpeg записывает новый звук, субтитры SRT / VTT / ASS и метку `AI-dubbed`.

## Ограничения

- Без CrisperWhisper (необязательный движок 13) faster-whisper может пропускать речь или выдумывать текст на китайском и японском (замечено: пропущены первые ≈ 10 с китайского клипа; крик превратился в длинную строку "ああ…").
- CI проверяет только CPU; путь GPU запускался вручную на одной карте Pascal 4 ГБ. Новые карты (RTX 50), Linux и macOS не проверялись; установленные GPU-библиотеки содержат ядра от Pascal до RTX 50, Maxwell использует профиль CPU ([GPU runtime matrix](docs/installation.md#1-system-requirements)).
- Офлайн-переводчик переводит только с английского на турецкий; для других пар нужен Codex / Claude Code CLI или API-бэкенд.
- Метки времени слов для исходных языков, кроме английского и турецкого: японский и китайский через `scripts/kur.ps1 -Adim hizalama-diller`, остальные после одного запуска с `DUBLAJ_CEVRIMICI=1`.
- Не проверено от начала до конца: реальная установка XTTS-v2, RVC, Telegram-бот с настоящим сервисом. CrisperWhisper 2.0 Turbo (движок 13) проверен на реальном аудио на GTX 1050 Ti 4 ГБ (tr, en, ja; ≈ 1,4 ГБ VRAM).

## Строительные блоки

Каждый этап работает отдельно, из командной строки или из Python, с документированными форматами файлов между этапами
(карта этапов и JSON-схемы: [docs/mimari.md](docs/mimari.md)):

```bash
dubla yaziya-dok talk.mp4 -o talk.json          # speech-to-text + word times (also: indir, ses-cikar, ayir, hizala)
dubla cevir talk.json -o talk.tr.json            # translation, timing kept
dubla seslendir talk.tr.json -o tts/             # timed speech (or plain text -> WAV)
dubla altyazi talk.json --kip karaoke -o k.ass   # SRT / VTT / ASS, word and karaoke modes
dubla birlestir talk.mp4 -o out.mp4 --ses tts/speech.wav --altyazi talk.tr.srt
```

`from dublaj_hatti import api` даёт те же этапы в виде функций. Устанавливайте только то, что нужно этапу, например
`pip install -e ".[stt,hizalama,cpu]"` для субтитров. Пять небольших инструментов из этих блоков: [examples/](examples/).

| [voxcpm2-turkce-ses-tasarimi](https://github.com/alexturkey/voxcpm2-turkce-ses-tasarimi) | дизайн голоса и чтение на VoxCPM2, 8 языков, готовые голоса | дополнительный TTS-движок `voxcpm2`: `scripts/kur.ps1 -Adim voxcpm2` ставит его на фиксированном коммите; этот репозиторий вызывает его через тонкий адаптер |
